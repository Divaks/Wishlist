# Git workflow

## Branch naming

Use `WL-<number>` for pull request branches. The suffix is the pull request
number assigned by GitHub, using decimal digits without leading zeros.
For example, PR #6 uses `WL-6`, and PR #7 uses `WL-7`. Use the next
available number in the GitHub sequence for the next PR.

Before opening a PR, check the latest GitHub numbering and use the expected
number for the branch. Verify the assigned PR number after creation. If the
numbers differ, report the mismatch and coordinate how to correct the branch
or PR before making changes to an existing remote branch.
